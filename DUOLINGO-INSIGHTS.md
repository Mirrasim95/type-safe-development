# Duolingo Engineering Insights

## TypeScript

TypeScript helps us type data, components, and more. This helps us avoid errors when scaling the project. Also, while writing code, TypeScript allows us to see errors in real time before running the application.

## Zod

Zod handles data validation. For example, you can set a minimum number of characters for an input and display a warning if the condition is not met. You can also specify banned words that cannot be sent in the chat.

## Error Boundary

Error Boundary is used to catch errors when they occur and show the user a friendly message instead of a blank white screen.

## What Was Most Challenging

Using Zod together with TypeScript. Also the class-based component for ErrorBoundary. Writing types in TypeScript was also challenging at first.
